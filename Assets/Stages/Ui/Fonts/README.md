# Fonts — drop files here

The `.uss` files reference:

- `Assets/Fonts/Inter-Regular.ttf`
- `Assets/Fonts/Inter-Bold.ttf`

Drop any TTF/OTF with those names (Inter is the suggested face:
https://rsms.me/inter/, SIL OFL). If absent, the UI runtime falls back to
Guinevere's bundled `font.ttf` and the FontAwesome icon font (issue #18).
