# Models — drop files here

For the 3D-computer showcase (`Assets/Scenes/computer.prefab`):

- `monitor.glb` — a desktop monitor. Its screen face is where the world-space
  `UiDocumentComponent` panel is positioned. Any glTF/FBX works.
- `room.glb` *(optional)* — a small room / desk for context. A large scaled cube is
  a fine stand-in.

If nothing is provided, use the engine's built-in `cube.obj` (see other samples) as
the monitor and skip the room.
